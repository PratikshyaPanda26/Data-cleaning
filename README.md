# Customer Data Cleaning using Python

## 📌 Project Overview
This project demonstrates how raw customer data can be cleaned and prepared for analysis using Python. 
The dataset contains common real-world data issues such as missing values, invalid emails, incorrect ages, and inconsistent records.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy

## 📂 Dataset Issues Handled
- Missing values
- Invalid email formats
- Invalid age values (negative or unrealistic)
- Duplicate records
- Data type inconsistencies

## ⚙️ Key Features
- Data quality check report
- Removal of invalid records
- Creation of derived columns:
  - Full Name
  - Days Since Registration
- Data quality flag (Complete / Incomplete)
- Export of cleaned data to CSV

## 📊 Project Workflow
1. Load raw customer data
2. Identify data quality issues
3. Clean and validate data
4. Generate summary report
5. Export clean dataset

## 📁 Files Included
- `datacleaning.py` – main Python script
- `raw_customers.csv` – raw dataset
- `clean_customers.csv` – cleaned output dataset

## 🚀 Output
Cleaned dataset with only valid customer records, ready for analysis or further processing.

## 📌 Use Case
This project is useful for:
- Data preprocessing
- Customer analytics
- Real-world data validation before machine learning
